# Malverk pack importer spec (v1)

Converts an existing Malverk texture pack into a ReskinStudioRanked user pack
(`FORMAT.md`). **One spec, two implementations**: the launcher (C++, `ReskinFolder`
neighbourhood) and the Reskin Studio (TypeScript, next to `importRanked.ts`). They must
produce the same result for the same input; section 11 defines how that is checked.

Shared data: [`positions.json`](positions.json) - for every sheet, the grid size, `order` (key order for output) and the
vanilla cell `[x, y]` of every object key. Generated by `tools/gen_positions.js` from the
Studio catalog (plus seal and stake positions the catalog lacks; stake cells were read from the
game's own `game.lua`). Every layout rule below uses it; neither implementation may carry its own copy.

## 1. Security model (the point of the design)

The pack is untrusted third-party code. **The importer never executes, loads or evaluates
Lua.** It extracts a small amount of *literal data* from the Lua source with its own tokenizer
(section 4); anything it can't read as a literal is reported and skipped, never guessed at.
Everything that comes out is plain PNG/JSON, and the launcher still runs the normal
`ReskinFolder::validate()` over the result before it is ever used, so a bug here can produce a
wrong-looking pack but not a Ranked-illegal one.

Hard limits (reject the whole import when exceeded):

| limit | value |
|---|---|
| files scanned in the pack | 2000 |
| a `.lua` file read | 2 MiB each, 16 MiB total |
| a PNG read | 16 MiB, and header dimensions <= 16384 x 16384 and <= 64 Mpixels, **checked from the IHDR before decoding** |
| Lua nesting depth in a table literal | 16; tokens per file 1,000,000 |
| zip | uncompressed total <= 512 MiB, entries <= 2000, no entry name with `..`, an absolute path, a drive letter or a backslash escape; no symlink entries |

Symlinks/junctions/shortcuts inside a folder pack are skipped (not followed). Tokenizing is a
single linear pass: no regular expressions on file contents, no recursion over input depth beyond
the cap, so a hostile file can't cause quadratic or exponential work.

## 2. Input

A folder (an installed mod) or a `.zip` (STORE or deflate in the launcher via the existing
extractors; STORE only in the Studio, with the same "unsupported zip" error as `importRanked.ts`).

Find the pack root with the same rule as the launcher's canonical mod flatten: unwrap single
wrapper directories; the root is the folder containing a Steamodded manifest (a `.json` with a
string `id` and `main_file`, or a `.lua` beginning `--- STEAMODDED HEADER`). A Thunderstore zip's
`manifest.json`/`README.md`/`icon.png` at the top are ignored. No manifest found: use the single
shallowest folder that contains `assets/`.

A pack is a Malverk pack if the scan finds at least one `AltTexture` definition. Otherwise
report "not a Malverk texture pack" (section 9 has the optional manual fallback).

## 3. What is read

- Every `.lua` file under the pack root (this is how texture definitions are found; packs
  split definitions across files and load them with `SMODS.load_file`/`NFS.load`, so the
  manifest's `main_file` is not enough).
- `assets/1x/*.png` and `assets/2x/*.png` referenced by the definitions (resolved case-sensitively,
  falling back to case-insensitive on Windows paths; the name may not contain `/`, `\`, `..`).
- `localization/*.lua` data tables (section 8) and `assets/sounds/*.ogg` (section 9).

## 4. Lua literal extractor

Tokenize Lua 5.1 / LuaJIT: comments (`--`, `--[[ ]]`, `--[==[ ]==]`), strings (`'..'`, `".."`
with the standard escapes, `[[..]]` long strings), numbers (decimal, hex, floats), names,
punctuation. No evaluation.

Find calls whose callee is exactly `AltTexture` or `TexturePack` (also `SMODS.Sound`), in either
call form: `AltTexture({ ... })` or `AltTexture{ ... }`. The single argument must be a **table
constructor**. Parse it into a value tree where a *literal* is: a string, a number, `true`,
`false`, `nil`, or a table constructor of literals (array part, `name = v`, `["str"] = v`,
`[number] = v`, trailing separators allowed).

Any other expression in a field - a variable, a call, `..` concatenation, arithmetic, `#t`,
a function - makes **that field unresolved** (it stays "unresolved", it is not skipped silently;
the parser keeps going with the next field). A call inside a loop, `if`, or function body is
read like any other occurrence, once, at its source position; it is treated as one definition
whatever the loop would have done at runtime.

Optional v1 nicety (not required for conformance): resolve one level of file-scope
`local NAME = <literal>` bindings that appear before use, with no reassignment anywhere in the
file. Both implementations must either both do this or both not; the fixtures cover it as a
separate group.

Fields read from an `AltTexture`: `key`, `set`, `path`, `keys`, `original_sheet`, `frames`,
`px`, `py`, `soul`, `soul_keys`, `stickers`, `localization`. A definition with `set` or `path`
unresolved is skipped with a warning (reason: which field). An unresolved `keys` makes that
texture skipped too (without `keys` it would silently mean something different). Other
unresolved fields are ignored unless noted.

From a `TexturePack`: `key`, `textures` and `toggle_textures` (lists of AltTexture keys; the README has packs write them
mod-prefixed, `<modprefix>_<altkey>`, so an entry matches an AltTexture when it equals its
`key` or ends with `_` + its `key`; an ambiguous or unmatched entry is a warning).

and shaders are also dropped with a warning (their *cell accounting* still matters, see 6.2).

## 6. Layout resolution (per AltTexture)

Source atlas: the PNG named by `path`. `px`/`py` default to the set's cell size from
`positions.json` (`cellW`/`cellH`). Columns = `imageWidth(1x) / px`.

### 6.1 Which case

Malverk's rule: `original_sheet = original_sheet or not keys`.

- **A. vanilla layout** (`original_sheet` true, or no `keys`): the sheet has the vanilla cell
  layout. The object's source cell is its `positions.json` cell.
  `keys` given: only those objects; absent: every key of the set in `positions.json`.
- **B. packed layout** (`keys` given and `original_sheet` not true): the i-th key in `keys` (1-based)
  has its cell at `index = (i - 1) + souls_before(i)`, `x = index % columns`,
  `y = floor(index / columns)`, where `souls_before(i)` is the number of keys *before* position `i`
  that are in `soul_keys`. A key that is in `soul_keys` also owns the next cell (`index + 1`),
  the floating soul layer, which is read past, not imported.

Keys that are not in `positions.json` (modded/unknown) are skipped with a warning naming the key.

### 6.2 Cell extraction

For each covered key: read the cell `px*scale x py*scale` at the resolved (x, y) from the
source, place it at the key's `positions.json` cell `[x, y]` in the output sheet.
Blind (`frames`): the source row holds `frames` frames; copy all 21 into the output row;
a source with a different `frames` count is resampled by nearest-frame to 21, with a warning.
A cell that lies outside the source image is skipped (warning), not an error.
An all-transparent cell is treated as **not covered**: the key is dropped from `keys` (a
pack that leaves cells empty to mean "no change" must not blank the vanilla art).

### 6.3 Scale and size

`scale` is the file's own: if `assets/2x/<path>` exists, use it as the source (2x -> `scale = 2`),
else `assets/1x/<path>`. A source whose size isn't a whole number of cells is an error for that
texture. Output dimensions are exactly the `positions.json` vanilla size (`cols*cellW` x `rows*cellH`),
1x and 2x. Each cell is resized to the output cell size with **nearest-neighbour** (pixel art must
not blur), also when `px`/`py` are non-standard (a warning says the art was resized). A missing
output scale is derived: 1x from 2x by taking every other pixel (nearest), 2x from 1x by doubling.

### 6.4 Several AltTextures for one set

Apply in Malverk's order: the textures listed in a `TexturePack.textures` list, in list order,
and later wins per key (the right-most pack is on top in Malverk's UI as well). With several packs
in one mod, take them in definition order. AltTextures that appear in no pack are applied after,
in definition order. `toggle_textures` are not applied. Output `keys` for a sheet is the union
of covered keys across the applied textures.

## 7. Output

Per set that has at least one covered key: `assets/1x/<sheet>.png`, `assets/2x/<sheet>.png`
(vanilla dimensions, transparent outside covered cells) and a `reskin.json` entry
`{ "sheets": { "<sheet>": { "keys": [...] } } }`, `keys` sorted in `positions.json` order.
Always emit `keys` (even for a full sheet) so objects the pack didn't draw stay vanilla.
Pack name suggestion: the Steamodded manifest `name` (sanitized).

## 8. Localization

Sources: `localization/<lang>.lua` files whose body is `return { ... }` with a literal table
(`default.lua` = `en-us`; other file names are used as the language code if they match
`^[A-Za-z0-9_-]+$`), and an `AltTexture.localization` literal table of
`key = { name = "..", text = {".."} , badge = ".."}` (becomes
`descriptions.<Set>.<key>` = `{ name, text }`; `badge` is dropped; for Booster use the `Other`
table as Malverk does).

Keep only strings and arrays of strings (nested objects allowed), depth <= 8, strings <= 4000
bytes, <= 50,000 entries, `__proto__`/`constructor`/`prototype`/dotted keys dropped. **Drop**
`descriptions.alt_texture`, `descriptions.texture_packs` (Malverk UI text, not game text),
and anything whose value is not data. Merge multiple sources per language, later over earlier.
Output `localization/<lang>.json`.

## 9. Sounds, and the manual fallback

- `SMODS.Sound{ key, path, replace }` with literal `path` and a literal `replace` that names a
  vanilla sound: copy the Ogg Vorbis file to `assets/sounds/<replace>.ogg` (filename must match
  `^[A-Za-z0-9_-]+\.ogg$`; the launcher's Vorbis-header and size checks apply). Anything without a
  `replace` adds a sound rather than replacing one; skipped with a warning.
- **Manual fallback (optional, implement after the core importer):** if no definitions could be
  extracted, list the pack's PNGs whose 1x or 2x dimensions exactly equal a vanilla sheet
  (`positions.json` size) and let the user assign each to a set. Case A only.

## 10. Result and UX

The importer returns a structured report before anything is committed:

```
{ imported: [{ sheet, objects: N, from: "<path>" }], localization: [lang...], sounds: N,
  skipped: [{ what, reason }], warnings: [string] }
```

The launcher shows it in the Reskin Packs dialog ("Import Malverk Pack...": pick a folder or
zip, review the report, name the pack, confirm), then runs the existing validate-and-replace
(`importBundle`) over a staged folder. The Studio shows the same report and loads the result
into the editor (via the `importRankedBundle` path). Nothing is written to the library or the
editor until the user confirms; a cancelled or failed import changes nothing.

## 11. Conformance

`fixtures/malverk/` (to be written with the implementations) holds small packs plus
`expected/`: the exact output file list, `reskin.json`, localization JSON, and each output
PNG's **decoded pixels** (PNG encoders differ between Qt and canvas, so compare pixels, not
bytes). Both implementations must match all of it. Cases:

1. Case A, full vanilla-layout jokers sheet, no `keys`
2. Case A with `keys` (partial)
3. Case B packed, plain
4. Case B with `soul_keys` (cell index shift, soul cells not imported)
5. Two AltTextures for one set in one pack (later wins)
6. `toggle_textures` ignored
7. 2x only, 1x only, both
8. Non-standard `px`/`py` (resized)
9. Blind with `frames` != 21
10. Tag, Seal, Stake, Booster sets
11. Transparent cells left out of `keys`
12. Localization: Lua file, `localization` table, dropped `alt_texture` subtree
13. Sound with `replace`
14. Unresolvable `set`/`path`/`keys` -> skipped with the named field
15. Hostile: IHDR claiming 60000x60000, zip with `../` entry, Lua file with a 1M-token comment,
    deeply nested table, loc string > 4000 bytes, `__proto__` key, a Lua loc file containing code
    (`os.execute`) - all rejected or skipped, nothing executed

## 12. Out of scope (v1)

Stake stickers, soul/floating layers, Malverk toggle textures, modded sets, shaders, anything
that needs running Lua to resolve (computed paths/keys). These are reported, never silently lost.
